*Project Overview

A complete windmill monitoring and control system designed for real-time performance tracking and safety management.

Uses a microcontroller to continuously measure key parameters like magnetic levels, flame detection, light intensity, temperature, and smoke levels.

Supports fault detection and automated safety alerts, including buzzer activation for abnormal conditions.

Includes a custom Android dashboard application built using Python (Kivy) in Pydroid 3, enabling remote access and monitoring.

Features an intuitive interface with animated circular gauges for clear visual feedback of real-time sensor values.

Communication with the microcontroller is handled through a USB serial interface using usb4a and usbserial4a.

Designed for remote and industrial applications where continuous operation, reliability, and safety monitoring are essential.
